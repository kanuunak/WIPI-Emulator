# 스킨 팩 규격 (format 1)

폰 그림 한 장 위에 **게임 화면 자리**와 **키 영역**을 정해 "옛날 폰 한 대"처럼 보이게 하는 묶음이다.
설정 > 화면 > 스킨에서 고르고, 스킨이 "없음"이면 키패드 테마와 배치 설정을 쓴다.

이 문서는 사람이나 AI가 폰 그림을 받아 스킨 팩을 만들 때 따르는 규칙이다.
앱의 검사 코드는 `android/app/src/main/java/com/parkjeongseop/wipi/SkinPack.kt`에 있고, 이 문서와 함께 바꾼다.

> **저장소 규칙(AGENTS.md 규칙 8)**: 실제 제품 사진이나 제조사·통신사 로고가 들어간 스킨은 저장소에 커밋하지 않는다.
> 개인 기기에서 개인 용도로만 가져와 쓴다. 저장소와 앱에 기본으로 넣는 것은 코드로 직접 그린 스킨(`demo/skins/make_skins.py`)뿐이다.

---

## 1. 묶음 구조

zip 하나에 다음 파일을 넣는다(폴더 하나 안에 들어 있어도 된다 — `skin.json`이 있는 폴더를 팩의 맨 위로 본다).

```
my_phone.zip
├─ skin.json               # 규격(아래)
├─ body_portrait.png       # 몸체 그림(키·테두리 포함, 화면 자리는 검게 또는 투명하게)
├─ pressed_portrait.png    # (선택) 모든 키가 눌린 모습. body와 같은 크기·위치
├─ body_landscape.png      # (선택) 펼친 화면(가로)용
└─ pressed_landscape.png   # (선택)
```

- 그림 형식: PNG(투명 가능), JPEG, WebP. 한 변 4096px 이하를 권장한다(넘으면 앱이 줄여 읽음).
- zip 최대 40MB, 압축을 푼 크기 최대 80MB.
- 파일 이름은 대소문자를 구분한다.

## 2. 그림 크기 (Galaxy Z Fold5 기준)

| 배치 | 쓰는 화면 | 권장 그림 크기 | 비율(가로/세로) |
|---|---|---|---|
| 세로 | 커버 화면(접은 상태) | **904 × 2316 px** | 약 0.39 |
| 가로 | 메인 화면 펼친 가로 | **2000 × 1560 px** | 약 1.28 |

- 앱은 `layouts` 중에서 **지금 화면 비율에 가장 가까운 배치**를 고른다. 세로 배치 하나만 있어도 동작한다(펼친 화면에서는 작게 가운데 놓임).
- 그림은 비율을 지켜 화면 가운데에 놓이고, 남는 여백은 `background` 색으로 칠한다.
- 커버 화면은 위아래 시스템 바를 빼면 약 904 × 2190 px다. 그림이 이보다 길면 조금 줄어든다.

## 3. skin.json

좌표는 모두 **그림의 픽셀**이고, 원점은 그림 왼쪽 위다. 사각형은 `[x, y, 너비, 높이]`로 쓴다.

```json
{
  "format": 1,
  "name": "Silver flip",
  "names": { "ko": "실버 폴더폰" },
  "layouts": [
    {
      "image": "body_portrait.png",
      "pressed": "pressed_portrait.png",
      "size": [904, 2316],
      "background": "#141414",
      "screen": [92, 128, 720, 960],
      "screenColor": "#000000",
      "fit": "contain",
      "pressTint": "#73808080",
      "icons": [700, 40],
      "keys": {
        "SOFT_L": [64, 1300, 196, 92],
        "OK": { "rect": [380, 1433, 144, 144], "shape": "oval" },
        "1": { "rect": [64, 1735, 244, 112], "shape": "round", "radius": 50 }
      }
    }
  ]
}
```

| 필드 | 필수 | 뜻 |
|---|---|---|
| `format` | ✔ | 항상 `1` |
| `name` | ✔ | 스킨 이름(영어 등 기본) |
| `names` | | 언어별 이름 `{ "ko": "…" }` |
| `layouts` | ✔ | 배치 목록(1개 이상) |
| `image` | ✔ | 몸체 그림 파일 |
| `size` | ✔ | 몸체 그림의 `[너비, 높이]`(px). 실제 파일 비율과 2% 이내로 같아야 한다 |
| `screen` | ✔ | 게임 화면 자리. **3:4(가로:세로) 권장**(예: 720 × 960) |
| `keys` | ✔ | 키 코드 → 영역(아래 4절) |
| `pressed` | | 눌린 모습 그림. 눌린 키는 그 키 영역만 이 그림으로 바꿔 그린다 |
| `pressTint` | | `pressed`가 없을 때 눌린 키 위에 덮는 색(`#AARRGGBB`). 기본은 회색 45% |
| `background` | | 그림 밖 여백 색(`#RRGGBB`). 기본 검정 |
| `screenColor` | | 화면 자리 중 게임이 안 덮는 부분 색. 기본 검정 |
| `fit` | | `"contain"`(기본): 게임 3:4를 지켜 가운데 / `"stretch"`: 화면 자리에 꽉 채움 |
| `icons` | | ⏸⚙ 버튼 묶음(가로 약 96dp × 세로 48dp)의 왼쪽 위 `[x, y]`. 없으면 그림 오른쪽 위 |

## 4. 키 코드

| 코드 | 키 | 코드 | 키 |
|---|---|---|---|
| `SOFT_L` | 왼쪽 소프트키 | `SOFT_R` | 오른쪽 소프트키 |
| `UP` `DOWN` `LEFT` `RIGHT` | 방향키 | `OK` | 확인(방향키 가운데) |
| `CALL` | 통화(초록) | `CLR` | 취소·지우기 |
| `0`~`9` | 숫자 | `*` `#` | 별표, 우물 정 |

- 키 하나는 `[x, y, w, h]`, 또는 `{ "rect": [x, y, w, h], "shape": "rect" | "oval" | "round", "radius": px }`로 쓴다.
  `shape`는 눌림 표시 모양에만 쓰이고, 누르기 판정은 항상 사각형이다.
- **종료(빨간 수화기, HANGUP) 키는 넣지 않는다.** 게임이 종료로 처리할 수 있어 받지 않는다. 그림에 있어도 영역을 비워 둔다.
- 빠진 키는 경고만 나오고 동작한다(그 키를 못 누를 뿐). 21개를 다 넣는 것을 권장한다.
- **원형 방향키**는 사각형 다섯 개로 나눈다(`demo/skins/make_skins.py`의 `dpad_keys`와 같다).
  바깥 반지름 R, OK 반지름 r, 중심 (cx, cy)일 때:
  - `UP` = `[cx−r, cy−R, 2r, R−r]`, `DOWN` = `[cx−r, cy+r, 2r, R−r]`
  - `LEFT` = `[cx−R, cy−r, R−r, 2r]`, `RIGHT` = `[cx+r, cy−r, R−r, 2r]`
  - `OK` = `{ "rect": [cx−r, cy−r, 2r, 2r], "shape": "oval" }`
- 방향키는 터치 키패드와 같은 조이스틱 규칙으로 동작한다(누른 채 미끄러지면 방향끼리 바뀌고, OK로는 안 바뀐다).
  숫자키는 누른 채 다른 숫자로 미끄러지면 바뀐다.

## 5. 만들 때 지킬 것

1. **화면 자리**: 그림의 화면 부분을 검게(또는 투명하게) 비우고, 그 사각형을 `screen`으로 쓴다. 3:4가 아니면 게임 둘레에 검은 띠가 생긴다(경고).
2. **키 크기**: 커버 화면 기준 키 하나가 그림 px로 **너비 150 이상, 높이 90 이상**(손가락 약 40dp)이면 누르기 편하다. 실제 폰 사진의 키가 작으면 그림을 키패드 쪽이 크게 보이도록 다듬는다.
3. **겹침 금지**: 키 영역끼리 많이 겹치거나(경고) 화면 자리와 겹치지 않게(경고) 한다.
4. **그림 밖 금지**: 모든 사각형은 `size` 안에 있어야 한다(오류).
5. **눌린 그림**: 몸체 그림을 복사해 키 부분만 어둡게 하거나 백라이트 색으로 바꾼다. 위치·크기가 몸체와 정확히 같아야 한다.
6. **확인**: 앱 설정 > 화면 > 스킨 > **키 영역 표시**를 켜면 화면 자리(하늘색)와 키 영역(분홍)이 선으로 보인다. 그림의 키와 선이 맞는지 본다.

## 6. 가져오기와 오류

- 설정 > 화면 > 스킨 > **스킨 팩 가져오기 (.zip)**.
- 검사에 실패하면 오류 목록(영어 원문)이 뜬다. **[복사]**를 눌러 그대로 AI에게 주면 고칠 곳을 알 수 있다.
  예: `layouts[0].keys.OK [95, 150, 10, 10] goes outside the image 100x200`
- 경고만 있으면 가져오기는 되고 경고 목록을 보여 준다.

## 7. AI에게 부탁하는 방법 (복사해서 쓰는 요청문)

폰 그림(정면 사진이나 제품 이미지)과 이 문서를 함께 주고 아래처럼 부탁한다.

```text
첨부한 폰 그림으로 docs/fold-retro/SKIN_FORMAT.md(format 1) 규격의 스킨 팩 zip을 만들어 줘.
- 세로 배치: 904 x 2316 px. 폰을 정면으로 똑바로 세우고 잘라서 이 크기에 맞춰(남는 곳은 투명).
- 화면 부분은 검게 비우고, 그 사각형을 screen으로(가능하면 3:4).
- 키 21개(SOFT_L SOFT_R UP DOWN LEFT RIGHT OK CALL CLR 0~9 * #)의 영역을 그림에서 재서 keys로.
  원형 방향키는 문서 4절 공식대로 다섯 사각형으로. 종료(빨간) 키는 넣지 마.
- 키가 작으면(너비 150px 미만) 키패드 부분을 키워서 다시 배치해 줘.
- pressed 그림: 몸체 그림에서 키 부분만 어둡게(또는 백라이트처럼 밝게) 한 같은 크기 그림.
- 가능하면 가로 배치(2000 x 1560: 가운데 화면, 왼쪽 방향키, 오른쪽 숫자키)도.
- 마지막에 키 영역을 선으로 덮은 확인용 그림도 보여 줘.
```

앱에서 가져온 뒤 "키 영역 표시"로 맞는지 보고, 어긋나면 그 화면을 캡처해서 다시 부탁한다.

## 8. 기본 스킨 다시 만들기

```sh
python3 demo/skins/make_skins.py   # demo/skins/<id>/ 와 android/app/src/main/assets/skins/<id>.zip 갱신
```

단위 테스트 `SkinPackTest.bundledSkinsAreValid`가 기본 스킨에 오류·경고가 없는지 확인한다.
